TTS

Text wird zur Stimme

Beim Audio sind das Hinterlegen von Videos mit gesprochenem Text und das Vorlesen von Texten besonders interessant. Das nennt sich Text to Speech, kurz TTS.

Weniger als zehn Sekunden Audiomaterial können genügen, um eine Stimme zu klonen. Mehr dazu bei den Risiken.

Für TTS gibt es viele Anbieter. Wenn keine Erzeugung in Echtzeit nötig ist, ist zum Beispiel Qwen3-TTS interessant.

Es kann – gute Hardware vorausgesetzt – lokal betrieben werden; auch die Stimme lässt sich per Prompt modellieren.

Unter der Oberfläche

Chatbots

Der Chat ist die Oberfläche. Das Sprachmodell ist die Basistechnologie.

Basistechnologie

Large Language Model

Was die meisten unter einem Chatbot verstehen, ist im Wesentlichen ein Large Language Model (LLM), zum Beispiel GPT 5.6 Terra, das über eine Reihe von Nachrichten eine Antwort erzeugt.

GPTGenerative
Pre-trained
Transformer

Transformer sind eine Architektur für neuronale Netzwerke, die besonders gut zur Sprachverarbeitung geeignet ist.

Beispiel

Ein Chat kann so ablaufen

Q„Was ist die Hauptstadt von Frankreich?“

A„Paris.“

Q„Kann man dort irgendetwas Tolles sehen?“

A„Ja, der Louvre oder der Eiffelturm könnten Dich interessieren.“

Wie ein Chat erinnert

Der gesamte Verlauf wird zum Kontext

Nachricht 1Nachricht 2…Neue FrageLLMAntwort
Je länger im selben Chatfenster geschrieben wird, desto länger wird der Kontext – und desto aufwendiger kann die Antwort werden.

Wissensdatenbanken

Was das Modell nicht weiß

Ein Chatbot mit dem richtigen LLM hat enormes Wissen – aber nur das Wissen, das im zugrunde liegenden Modell eintrainiert wurde. Ein einfacher Chatbot kennt weder die Zeitung von heute früh noch automatisch den aktuellen Wetterbericht.

Retrieval-Augmented Generation

RAG greift auf Wissensdatenbanken zu und reichert den Chat temporär mit relevanten Informationen an.

In Firmen wird das häufig genutzt, um internes Wissen leichter verfügbar zu machen.

Retrieval-Augmented Generation

So funktioniert RAG im Chatbot

Q„Steht heute etwas über die Bundestagswahl in der Zeitung?“

+Zeitung als Kontext einfügen

Q<Zeitungsinhalte>
„Steht heute etwas über die Bundestagswahl in der Zeitung?“

A„Ja, Frederik Merks von der GPD hat gesagt, es wird dank ihm bald keine Bundestagswahlen mehr brauchen.“

Üblicherweise werden Vektordatenbanken verwendet. Denkbar ist jeder Mechanismus, der relevante Zusatztexte findet.

Vom Antworten zum Handeln

KI-Agenten

LLM-Antworten müssen nicht zwangsläufig von Menschen gelesen werden. Sie können für die Weiterverarbeitung durch eine Maschine bestimmt sein.

Ein Modell kann nach Informationen fragen, nach relevanten Daten suchen oder ein Computerprogramm ausführen lassen.

PlanenTool wählenAusführenBewertenWeiterarbeiten

Tool Calling

Das Modell beschreibt – das Backend handelt

Beispiele und Einordnung

Tools: Websuche, Wetterbericht, E-Mail-Versand, Telegram-Nachrichten oder die Kommandozeile des Nutzer-PCs.

LLMs verarbeiten Text sowie – je nach Modell – Bilder und Audio als Eingaben und erzeugen Text. Das Backend setzt den eigentlichen Tool-Aufruf um; das LLM beschreibt Tool und Parameter.

Plant ein System Aufgaben in mehreren Schritten, wählt Tools, bewertet Ergebnisse und arbeitet weiter, spricht man häufig von einem KI-Agenten. Beispiele sind Claude Code und Codex.

Denkanstoß: Was geschieht, wenn ein Tool Agenten erlaubt, weitere Agenten auszuführen und damit selbst in die Rolle des Users zu schlüpfen?

Vertrauen und Zugriff

Zwei Risiken, eine Konsequenz

Halluzinationen

Sprachmodelle können Fakten, Quellen, Zitate oder Zusammenhänge erfinden – und dabei überzeugend klingen.

Dass KI Fehler macht, ist ein Risiko. Ein weit größeres ist, ihr blind zu vertrauen.

Websuche, RAG und Quellen helfen, machen eine KI aber nicht automatisch zuverlässig.

Prompt Injection

Angreifer verstecken Anweisungen in Webseiten, E-Mails oder Dokumenten. Ein autonomer Agent könnte sie fälschlich als Auftrag verstehen.

Je mehr ein Agent darf und vom User weiß, desto größer ist der mögliche Schaden.

Besonders kritisch: E-Mails, Cloud-Daten, Konten, Passwörter und vertrauliche Dokumente.

Kontrolle ist unverzichtbar – besonders bei Medizin, Recht, Finanzen und Politik.

So sind die Werte einzuordnen

Die Werte sind eigene, begründete Szenarioschätzungen für den potenziell durch KI einsparbaren Anteil menschlicher Arbeitszeit bei vergleichbarer Qualität – nach Abzug von Kontrolle und Nacharbeit.

Angenommen werden geeignete Digitalisierung und eingerichtete Systeme. Die Bandbreiten sind keine statistischen Konfidenzintervalle, keine gemessenen Automatisierungsquoten und keine Prognosen des Stellenabbaus. Sie sind nicht direkt mit den Wahrscheinlichkeiten von 2013 vergleichbar. Stand: September 2026.
